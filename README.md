# WhatsNext Vision Motors – Salesforce CRM Project

## Project Overview

WhatsNext Vision Motors is a Salesforce-based CRM application developed to manage vehicle dealership operations.

The application manages:

- Vehicle Inventory
- Dealer Information
- Customer Information
- Vehicle Orders
- Test Drives
- Service Requests

## Key Features

### Vehicle Management
- Manage vehicle model, brand, price and stock quantity.
- Automatically maintain vehicle availability.

### Order Management
- Create customer vehicle orders.
- Validate vehicle stock before placing an order.
- Prevent orders when the vehicle is out of stock.
- Automatically assign the nearest dealer.

### Test Drive Management
- Schedule customer test drives.
- Automatically send a reminder email one hour before the scheduled test drive.

### Service Request Management
- Create customer service requests.
- Automatically update new service requests to In Progress.
